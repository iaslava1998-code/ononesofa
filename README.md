# На одном диване

Киносайт для двоих. **Next.js + Supabase + TMDB**.

## Что уже сделано
- Каталог с постерами и списком из 22 фильмов.
- «Хотим посмотреть» и «Посмотрели» по наличию хотя бы одной оценки.
- Общий PIN и редактирование двух оценок (нужна серверная настройка).
- Поиск и добавление фильмов из TMDB (нужен ключ).
- Адаптивный дизайн.

## Запуск
`npm install && npm run dev`

## Настройка для настоящей общей работы
1. Создайте проект Supabase и выполните `supabase/schema.sql` в SQL Editor.
2. Добавьте строки `data/films.json` в таблицу `films`, чтобы начальные фильмы и оценки сохранялись сервером.
3. В Vercel → Project Settings → Environment Variables заполните значения из `.env.example`.
   - `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` берутся из Supabase. **Никогда не вставляйте service role key в GitHub.**
   - `SITE_PIN` — придуманный общий PIN, `SITE_SESSION_SECRET` — случайная длинная строка.
   - `TMDB_API_KEY` — TMDB API Read Access Token (Bearer).
4. Разверните репозиторий через Vercel.

**Важно:** пока Supabase не настроен, галерея демонстрирует исходные данные, но не сохраняет изменения. PIN и поиск также не работают без переменных окружения.
